# 🚀 Mastering Loops, Iteration & Logical Thinking (Java)

This repository is a structured collection of **125+ Java problems** focused on mastering:

* Loops (`while`, `do-while`, `for`)
* Nested iteration
* Control flow (`break`, `continue`)
* Mathematical logic
* Dry-run thinking (step-by-step execution)

The goal is to build a **strong problem-solving foundation before diving deep into Data Structures & Algorithms (DSA)**.

---

## 📌 Why This Repository?

Before solving complex DSA problems, it's critical to:

* Think logically
* Trace code mentally (dry run)
* Write clean iterative solutions
* Understand edge cases

This repo is designed to strengthen these fundamentals.

---

## 🧠 What You'll Learn

* Writing efficient loop-based solutions
* Breaking down problems into smaller steps
* Improving debugging and dry-run ability
* Recognizing patterns in problems
* Building confidence for coding interviews
